# Learning Gate demo

A demo of **Learning Gate**, a Grade 1 learning app (math, reading, sight-word stories, bedtime stories).
It uses a made-up child ("Ava") with sample progress. Nothing you do on the page is sent anywhere;
progress stays in your own browser. Grown-ups PIN in the demo: **1234**.

**Open the demo:** https://hinga92.github.io/learngate-demo/
